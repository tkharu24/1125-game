# Number Plate（9×9 ナンプレ）

HTML・CSS・JavaScript を単一ファイル（[`Number Plate.html`](Number%20Plate.html)）にまとめた、ブラウザでそのまま遊べる 9×9 のナンプレ（数独）ゲームです。

## 概要

- **自動生成パズル（唯一解保証）**：毎回ランダムに完成盤面を生成し、解が 1 通りに定まることを確認しながらマスを空けて出題します。
- **3 段階の難易度**：初級・中級・上級から選べます。
- **正解照合＆ミス制限**：間違った数字を入力するとミスがカウントされ、3 回ミスするとゲームオーバーになります。
- **自動保存対応**：プレイ中の盤面やメモ、経過時間、難易度別ベストタイムをブラウザの `localStorage` に自動保存します。

---

## 遊び方（操作方法）

1. [`Number Plate.html`](Number%20Plate.html) をブラウザで開きます（サーバー不要）。
2. 空いているマスをクリックまたはタップして選択し、数字を入力します。
3. すべての行・列・3×3 ブロックに `1〜9` が重複なく入るように埋めるとクリアです。
4. 不正解の数字を入れるとマスが赤く表示されてミスが +1 されます（メモ入力中はミスになりません）。ミスが 3 回に達するとゲームオーバーとなり、「同じ問題をやり直す」か「新しい問題」を選べます。

### 画面ボタン

| ボタン | 内容 |
| --- | --- |
| **初級 / 中級 / 上級** | 難易度を切り替え、新しい問題を開始します |
| **一時停止 / 再開** | タイマーを止めて盤面を隠します |
| **戻す** | 直前の操作（メモ編集・消去・誤入力など）を 1 手戻します |
| **消す** | 選択中のマスに入力した誤答やメモを消去します |
| **メモ** | 通常入力モードと候補メモモードを切り替えます |
| **ヒント** | 選択中の空きマス（未選択時は空きマスからランダム）に正解を入れます（1 ゲーム 3 回まで） |
| **1〜9 パッド** | 数字を入力します。ボタン下部に残り必要数（`残X`）が表示され、9 個揃うと「完了」になります |
| **新しい問題** | 現在の難易度で新しい盤面を生成します |

### キーボード操作

- `1`〜`9`：数字の入力（メモモード時は候補の ON/OFF）
- `↑` `↓` `←` `→`：選択マスの移動
- `Backspace` / `Delete` / `0`：選択マスの数字・メモを削除
- `M`：メモモードの切り替え
- `H`：ヒントを使用
- `Z`（または `Ctrl + Z`）：1 手戻す

## 工夫した点

（※コミット履歴は初回コミット `ffe8e57` の 1 件のみであるため、同コミットに含まれる実装内容をもとに記載しています）

- **1 ファイル完結・レスポンシブ設計**
  - 外部ライブラリやビルドツールに依存せず、PC・スマートフォンのどちらでも 1 画面に収まるシンプルなレイアウト（白・グレー基調）で実装しました。
- **MRV 付きバックトラッキングによる唯一解チェック**
  - 問題生成時に、候補数が最小の空きマスを優先して探索する `countSolutions` を実装し、どの難易度でも別解のない問題を出題するようにしています。
- **遊びやすさを支える補助 UI**
  - 選択マスの行・列・3×3 ブロックの背景ハイライトに加え、同じ確定数字やメモ内の該当候補も強調表示します。
  - 正解の数字が確定すると、同じ行・列・3×3 ブロック内のメモからその数字を自動で消去します。
  - 数字パッドに各数字の残り個数を表示し、入力完了した数字を視覚的に区別できるようにしました。
  - 同じ誤入力を連続で押しても二重にミスカウントしないよう制御し、ミス時は軽いシェイクアニメーションで気づきやすくしています。
- **プレイ状態の永続化とタイマー制御**
  - `localStorage` によりリロード後も途中から再開できるほか、ブラウザのタブが非表示の間はタイマーが進まないようにしています。

## 作りながら変えた点

（※リポジトリのコミット履歴は初回コミット `ffe8e57` のみのため、制作中の仕様相談から初回コミットに至るまでの変更・調整内容をまとめています）

- **ファイル名とゲーム仕様の具体化**
  - 初期の設計案では `index.html`・ヒント回数制限未定としていましたが、ファイル名を [`Number Plate.html`](Number%20Plate.html) に変更し、ヒントを **1 ゲーム 3 回まで**・**自動保存あり** の仕様に確定しました。
- **正解確定・ヒント使用時の「戻す（Undo）」挙動の修正**
  - 実装時の見直しで、すでに正解として確定したマスを保護する設計と Undo 履歴が噛み合わず、「正解やヒントを入力した直後に『戻す』が押せるのにマスが戻らない」不整合が起きる点に気づきました。そのため、正解確定時およびヒント使用時に Undo 履歴をリセットし、確定前・誤答修正などの戻せる操作だけが履歴対象になるよう調整しました。
- **難易度切り替え時の確認ダイアログ追加**
  - 最初は同じ難易度タブを押した場合のみ進行中ゲームの確認ダイアログを出していましたが、プレイ中に誤って別の難易度タブを押して進捗が消えるのを防ぐため、他の難易度へ切り替える際も経過時間がある場合は確認を出すように変更しました。
